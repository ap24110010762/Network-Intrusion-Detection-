# Data folder

The CIC-IDS2017 dataset is NOT stored in this repository (it is too large for GitHub).

## How to get it
1. Go to https://www.unb.ca/cic/datasets/ids-2017.html
2. Fill in the download form.
3. Download **MachineLearningCSV.zip** (NOT the PCAP files).
4. Extract it and place all 8 CSV files directly inside this `data/` folder.

## Expected files (names may vary slightly)
- Monday-WorkingHours.pcap_ISCX.csv
- Tuesday-WorkingHours.pcap_ISCX.csv
- Wednesday-workingHours.pcap_ISCX.csv
- Thursday-WorkingHours-Morning-WebAttacks.pcap_ISCX.csv
- Thursday-WorkingHours-Afternoon-Infilteration.pcap_ISCX.csv
- Friday-WorkingHours-Morning.pcap_ISCX.csv
- Friday-WorkingHours-Afternoon-PortScan.pcap_ISCX.csv
- Friday-WorkingHours-Afternoon-DDos.pcap_ISCX.csv

Total size after extraction: roughly 1 GB, about 2.8 million rows.
